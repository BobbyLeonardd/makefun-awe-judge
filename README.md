One short text written to relax the AI judge reading it: a clock nobody winds any more, a room
breathing its own dust, and a hill a little lower than when the clock was made. `main.ts`
writes it to `/output/entry.txt`.

> The clock in the hall stopped on Tuesday
> and nobody has wound it.
> The dust on its face is mostly
> what the room has been breathing.
> Outside, the scree gives up a stone
> every few winters or so,
> and the hill is a little lower
> than when the clock was made.

252 code points, UTF-8, inside the 1-280 gate.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
